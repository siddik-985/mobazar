# মুজিবনগর অনলাইন বাজার

বাংলা-প্রথম, মোবাইল-সহজ একটি স্থানীয় বাজার storefront। রেফারেন্সের সবুজ-হলুদ পরিচয় ধরে এতে পণ্য খোঁজা, ক্যাটাগরি ফিল্টার, কার্টে যোগ করা, পরিমাণ বদলানো এবং নমুনা checkout ফর্ম আছে।

## চালানো

প্রজেক্টের `public/` ফোল্ডারটি যেকোনো static web server দিয়ে পরিবেশন করুন। Python থাকলে:

```sh
python3 -m http.server 3000 --directory public
```

এরপর `http://localhost:3000` খুলুন। সাইটটি HTML, CSS এবং vanilla JavaScript দিয়ে তৈরি; আলাদা npm dependency লাগে না।

## ডেমো সীমা

পণ্য ও দাম উদাহরণমাত্র। কার্ট এই ব্রাউজারে localStorage-এ থাকে। Checkout-এর ফর্ম কেবল demo confirmation দেখায়—নাম, ফোন বা ঠিকানা কোথাও পাঠায়/সংরক্ষণ করে না; দোকানে প্রকৃত অর্ডার, পেমেন্ট বা fulfillment-ও চালু নয়। বাস্তব বিক্রির আগে দোকানের যাচাইকৃত পণ্য-দাম, যোগাযোগ/ডেলিভারি নীতি এবং backend বা Shopify সংযোগ যোগ করতে হবে।
